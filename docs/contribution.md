## 🏷️ Conventional Commits

We follow [Conventional Commits](https://www.conventionalcommits.org/): each commit
summary starts with a type describing the change.

- `feat:` — a new feature (e.g. `feat: add user login session`)
- `fix:` — a bug fix (e.g. `fix: resolve crash on null profile image`)
- `refactor:` — code change that neither fixes a bug nor adds a feature
- `docs:` — documentation only
- `chore:` — build tasks, dependencies, or config
